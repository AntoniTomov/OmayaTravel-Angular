# Problematic PR Register

This file tracks PRs that need architecture/process attention because review cycles are repeating.

A PR is added here when:

1. The Lead Architect leaves comments or requested changes on the same PR on three separate review occasions.
2. The requester resolves those comments.
3. On the fourth Architect review occasion, the Lead Architect still has new required comments.

Being listed here is not blame. It means the work order, approved specification, implementation approach, review criteria, or expert handoff may be unclear enough to deserve explicit correction.
